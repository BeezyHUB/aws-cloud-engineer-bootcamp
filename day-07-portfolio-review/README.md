
# Day 7 — AWS Cloud Engineering Portfolio Review

## Project Overview

Conducted a review of the first six days of my AWS Cloud Engineer Bootcamp, focusing on technical documentation, project organization, and foundational cloud engineering concepts.

Created a centralized GitHub portfolio to showcase my hands-on learning, infrastructure designs, and troubleshooting exercises.

## Technologies & Tools

- Amazon Web Services (AWS)
- Amazon VPC
- Amazon EC2 (architecture concepts)
- Terraform
- Ubuntu Linux (WSL)
- Bash
- GitHub
- Markdown

## Project Objectives

- Review completed bootcamp projects from Days 1–6.
- Organize technical documentation.
- Verify project descriptions and GitHub links.
- Identify areas requiring further practice.
- Build a professional cloud engineering portfolio.

## Work Completed

### 1. AWS Networking Review

Reviewed VPC architecture, public and private subnets, route tables, internet gateways, and network isolation.

### 2. Infrastructure as Code Review

Reviewed Terraform fundamentals, configuration files, and local infrastructure exercises.

### 3. Web Development Review

Reviewed the HTML website created during the bootcamp and its role in future web server exercises.

### 4. High Availability Architecture

Reviewed an AWS high-availability design incorporating:

- Application Load Balancer (ALB)
- Auto Scaling Groups (ASG)
- Multiple Availability Zones
- Public and private subnets

The architecture was designed and documented, not deployed.

### 5. AWS Security Review

Reviewed IAM concepts, access control, least privilege, and multifactor authentication (MFA).

### 6. Linux Administration Review

Reviewed Linux commands, file permissions, system monitoring, and the `health-check.sh` Bash script.

## Portfolio Organization

Organized the completed projects into a centralized GitHub repository with individual project documentation and a main README.

Completed a structured review of six foundational AWS Cloud Engineer bootcamp projects and organized their documentation into a professional GitHub portfolio.
